# 简介
BedrockBoot 是一款 Windows 下的 Minecraft 基岩版启动器，旨在帮您管理多版本，多实例的启动器。  
高效，快速的实现多版本，多实例启动。

# 特色功能
BedrockBoot v2.x 采用 OnePointUI 构建，现代化的界面，提升视觉的同时带来惊艳的效果。  
我们支持多版本，多实例并存启动，一次性玩不同存档，服务器不成问题！  
同时在 v2 版本中，我们引入了对 GDK 版本的支持。
